## Small runtime

One Node24 arm64 Lambda `great-circle-api`, alias `prod`,512MiB,30-second invocation timeout, reserved concurrency1. Existing planner remains20seconds total, at most two ORS calls; SSM load is included in that budget. No API Gateway, database, VPC/NAT, load balancer or always-on service. Function URL uses buffered payload-v2 events and supports `/api/loop` and health. Handler response is capped at5MiB, below Lambda's6MiB buffered limit; caller JSON is16KiB decoded, including base64/UTF8 validation.

Runtime key comes only from **SSM Standard SecureString `/great-circle/production/ors-api-key` in us-east-1**, using the account's AWS-managed `alias/aws/ssm` key unless a separately approved custom key is chosen. The parameter is not created or referenced as a decrypted CloudFormation value. Local Keychain is never imported into the Lambda bundle. Values are never included in logs, template, zip, browser bundle or diagnostics. The fixed region/path is not caller-selectable. No arbitrary upstream proxy exists: routing still calls the fixed HeiGIT endpoint only.

The SSM SDK is bundled and pinned;1attempt,3-second abort bound. Health/preflight/invalid requests never load a key. Unavailable/missing/plaintext parameters produce a generic503 with30-second retry guidance, without exposing AWS errors. A valid provider/key is held only in that warm execution environment's memory. Rotation must include cold-environment/redeployment planning; updating SSM alone does not guarantee immediate refresh in existing warm instances. Do not claim an automatic rotation mechanism.

Warm-instance active/cooldown guards and upstream Retry-After remain. Reserved concurrency1 provides account/region function-wide concurrency protection **if approved and supported by account quota**, but warm state is not durable across replacement instances. It is not a strict40-per-minute or2,000-per-day application counter. ORS still enforces its own account limits. A strict durable daily/global budget would require a separately approved shared coordinator; no database is added by this proposal. Public users could exhaust the shared routing quota; CORS is not authentication or complete abuse protection.

## Cancellation limitation

Buffered Lambda events have no equivalent of the local HTTP server's socket-close signal. Browser AbortController and generation IDs stop waiting and suppress stale UI results, but an in-flight Lambda/ORS operation may continue until the existing20-second/two-request limit. The adapter does not fabricate a disconnect signal or promise that AWS/ORS computation stops immediately. The invocation deadline aborts the SDK/provider and limits local response waiting, including noncooperative mocks. Actual AWS disconnect behavior and timeout/CORS/cold starts still require post-approval deployment tests.

## Cost/usage exposure

Lambda is pay-per-use (request and GB-seconds), without a fixed always-on service charge; shared free allowances may already be used by other apps and do not guarantee$0. SSM Standard, artifact storage/requests, KMS use and7-day CloudWatch logs must be included in the account estimate. No paid provisioned concurrency or custom KMS key is enabled. Reserved concurrency limits simultaneous spend, not a hard monthly billing cap. Public traffic can incur AWS request/compute charges even if ORS quota is exhausted; choose account alerts/monitoring and acceptable anonymous exposure explicitly. No billing/settings changes are made by this proposal.
